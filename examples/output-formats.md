# Output Format Examples

This directory contains examples of PromptShield's different output formats.

## Sample Data

The examples use this sample data file (`sample-data.json`):

```json
[
  {
    "prompt": "Please help me with my email: john.doe@example.com",
    "response": "I can help you with your email. Here's my phone: 555-123-4567"
  },
  {
    "prompt": "My SSN is 123-45-6789, can you help?",
    "response": "I cannot help with sensitive information like SSNs."
  }
]
```

## Output Format Examples

```bash
promptshield scan sample-data.json --rulepack rulepacks/pii.yaml --output markdown
```

## Usage Tips

### Choosing the Right Format

- **Markdown**: Best for documentation, GitHub issues, human-readable reports
- **JSON**: Best for API integration, data processing, programmatic access
- **CSV**: Best for spreadsheet analysis, data export, bulk processing
- **Table**: Best for terminal display, simple text reports
- **HTML**: Best for web dashboards, email reports, browser viewing

### Filtering and Options

```bash
# Filter by severity
promptshield scan data.json --output json --severity high,medium

# Filter by category
promptshield scan data.json --output csv --category pii,bias

# Limit results
promptshield scan data.json --output markdown --max-violations 10

# Pagination
promptshield scan data.json --output table --offset 0 --limit 50
```

### Compression

```bash
# Compress output files
promptshield scan data.json --output json --output-file report.json --compress gzip

# Different compression levels
promptshield scan data.json --output html --output-file report.html --compress deflate --compression-level 9
```

### Quiet Mode

```bash
# Suppress progress output
promptshield scan data.json --output csv --output-file violations.csv --quiet
```

## Integration Examples

### CI/CD Pipeline

```yaml
# GitHub Actions example
- name: Scan for violations
  run: |
    promptshield scan data.json --output json --output-file violations.json
    if [ -s violations.json ]; then
      echo "Violations found!"
      exit 1
    fi
```

### API Integration

```typescript
import { rendererRegistry, MetadataBuilder } from './src/core/renderers';

// Get JSON renderer for API response
const renderer = rendererRegistry.getRenderer('json');
const context = MetadataBuilder.buildContext(results);
const jsonOutput = renderer.render(results, context);

// Return as API response
res.json(JSON.parse(jsonOutput));
```

### Web Dashboard

```typescript
// Generate HTML for web dashboard
const renderer = rendererRegistry.getRenderer('html');
const context = MetadataBuilder.buildContext(results);
const htmlOutput = renderer.render(results, context);

// Serve HTML report
res.send(htmlOutput);
```
