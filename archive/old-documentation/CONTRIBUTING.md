# Contributing to PromptShield

Thank you for your interest in contributing! PromptShield is designed to be modular and extensible. Here’s how you can help:

## How to Add a New Rule Type

1. Review the rule engine internals in [RULE_ENGINE.md](./RULE_ENGINE.md).
2. Implement your rule type as a new strategy or plugin.
3. Add tests and documentation for your rule type.
4. Submit a pull request with a clear description.

## How to Add a New Output Format

1. Review the extension guidelines in [EXTENSIONS.md](./EXTENSIONS.md).
2. Implement your output formatter in the reporter system.
3. Add tests and update documentation/examples.
4. Submit a pull request.

## General Contribution Guidelines

- Follow the project’s coding standards and architecture principles.
- Write clear docstrings and comments.
- Add or update tests for all new features.
- Document your changes in the appropriate files.
- Be respectful and constructive in code reviews.
